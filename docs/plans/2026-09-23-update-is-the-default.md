# Update is the default

2026-09-23. A row of the import walk opens folded into the contact
its card looks like most, rather than as a new contact with the
update offered beside it. "new contact" stays the left side of the
toggle, asked for with an empty `into` where the update sides name a
contact; the track is centered over the editor. Nothing else about
the walk or the fold (`2026-09-23-merging-on-import.md`) changes.

## Why

New was the default on the argument that a change to something
already in the book is the importer's to make, not a score's. But an
import into a book that is not empty is mostly people the book
already has, so the default put the extra click on the common case —
and the walk's own posture already makes the choice the importer's:
nothing is written until the Save is pressed, and the folded editor
puts every clash in front of them before it is. The match is
offered, not believed; the other side of the toggle is one click,
and a wrong offer costs one look, as before.

This shades the old plan's non-goal "choosing a match automatically,
even an exact one": the choice is still made at the Save, but the
screen now opens already sitting on one side of it.
